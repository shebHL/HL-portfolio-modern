# Personal Portfolio

A modern portfolio landing page that introduces Henrietta Lisk, showcases selected work, and makes it easy for visitors to get in touch.

## About

This project is designed as a focused, responsive home for a creative professional, developer, or designer. It highlights:

- A clear introduction and personal brand
- Selected projects and case studies
- Skills, experience, or services
- A simple contact call to action

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

No build tools are required. Clone the repository and open `index.html` in a browser.

```bash
git clone <repository-url>
cd <project-folder>
open index.html
```

You can also use a local development server, such as the VS Code Live Server extension, for a smoother editing experience.
